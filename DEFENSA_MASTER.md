# Defensa de Máster

## Título
Desarrollo de una plataforma full-stack para la gestión integral de una protectora de animales

## 1. Introducción
Este proyecto tiene como objetivo diseñar y desarrollar una aplicación web completa que facilite la gestión de una protectora de animales, combinando una experiencia de usuario pública con un sistema de administración interno.

## 2. Justificación del proyecto
La gestión de una protectora implica múltiples procesos: adopciones, voluntariado, donaciones, organización de eventos y seguimiento de actividades. La propuesta desarrolla una solución digital que centraliza estas funciones y mejora la operatividad del centro.

## 3. Objetivos
- Crear una plataforma web funcional y usable.
- Permitir a los usuarios interactuar con la protectora de forma sencilla.
- Facilitar la gestión interna a través de un panel administrativo.
- Demostrar competencias en desarrollo full-stack, bases de datos y arquitectura de software.

## 4. Tecnologías utilizadas
- Frontend: React + Vite
- Backend: Node.js + Express + TypeScript
- Base de datos: Prisma + PostgreSQL
- Seguridad: autenticación, middleware y control de acceso
- Despliegue: scripts de instalación y ejecución local

## 5. Funcionalidades desarrolladas
### Funcionalidades públicas
- Visualización de animales disponibles para adopción.
- Formulario de adopción para usuarios interesados.
- Registro de voluntarios y gestión de disponibilidad.
- Formulario de donaciones con selección de tipo de aportación.
- Visualización de eventos y actividades de la protectora.

### Funcionalidades de administración
- Panel de control con métricas generales.
- Gestión de animales: alta, baja y modificación.
- Gestión de eventos con imágenes.
- Gestión de solicitudes de adopción.
- Gestión de voluntarios y donaciones.
- Acceso seguro para administradores.

## 6. Metodología
El proyecto se ha desarrollado siguiendo una arquitectura modular, separando frontend, backend, rutas, servicios y base de datos. Esta estructura mejora la mantenibilidad y permite escalar la solución en futuras versiones.

## 7. Resultados obtenidos
Se ha construido una aplicación funcional que demuestra cómo una protectora puede digitalizar sus procesos principales. El resultado es una solución práctica, completa y preparada para ampliarse con nuevas funcionalidades.

## 8. Conclusión
Este proyecto demuestra la capacidad de desarrollar una solución tecnológica realista, aplicando conocimientos de programación, diseño de interfaces, gestión de datos y desarrollo backend. Además, supone una base sólida para futuras mejoras y para su integración en un entorno real.
